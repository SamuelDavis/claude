# Documentation

- **Precision.** Use the exact technical term, or its nearest approximation. Terseness follows from precision.
- **Single source of truth.** Reference the source; don't restate it.
- **Intent and contracts, not implementation.**

## README.md

The README.md should act as a handoff document by orienting a fresh coding session to the project's conventions, architecture, and intent, enabling consistent contribution without exhaustive exploration.
